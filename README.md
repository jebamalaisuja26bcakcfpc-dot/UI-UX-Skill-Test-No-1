# Instagram UI/UX Design

## 📌 Project Overview

This project is a UI/UX design inspired by a social media application like Instagram.  
The design focuses on creating a simple, modern, and user-friendly interface with a dark theme.

The project was designed using Figma as part of a UI/UX skill test.

## 🎯 Objective

The main objective of this project is to design a social media application interface that is:

- Simple and easy to use
- Modern and attractive
- User-friendly
- Consistent across different screens
- Easy to navigate

## 📱 Screens Designed

The project includes the following screens:

1. Home Screen
2. New Post Screen
3. Search Screen
4. Reels Screen
5. Notification / Messages Screen
6. Profile Screen

## 🎨 Design Features

- Dark theme interface
- Clean and organized layout
- Simple navigation bar
- Story section
- Post and image sharing interface
- Search functionality
- Reels interface
- Messages and notification section
- User profile section
- Consistent icons and spacing

## 🛠️ Tools Used

- Figma
- UI/UX Design
- Prototyping
- Mobile App Design

## 🔄 User Flow

Home → Search → Reels → Messages → Profile

Users can easily navigate between the main sections using the bottom navigation bar.
